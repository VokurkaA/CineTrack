# CineTrack

Your movie and series tracking platform.

## Built With

- **Next.js 16** (App Router)
- **React 19**
- **Tailwind CSS v4**
- **HeroUI**
- **Better Auth**

## Local Development

```bash
npm install
npm run dev
```

## Features

- [x] Internationalization (en, cs)
- [x] HeroUI Components
- [ ] Authentication (Better Auth)
- [ ] Movie/Series Search
- [ ] User Watchlist
